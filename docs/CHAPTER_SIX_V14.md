## 物語と継続性

サハリアで取り戻した羅針盤、ナディアの地図、ラシードの歌の写しが北の霜境を示す。クロノリアの住民は夜明け前の短い時間を繰り返し、完全に静止してはいない。案内人エイルは姉ミラを探し、時計技師オルフェンは修復後に記憶の順序が一致しない代償を恐れている。

主題は「過去を取り戻すか、未来へ進むか」。アステルは失敗を消す誘惑より今の決断を選ぶ。リナは守れなかった声を忘れず、今目覚める人を支える。メイは歌の間隔が帰還者を数える機構だったと読む。フィオの合図、セレナとエコーリアの記録、ザイラが返した羅針盤を自然につなぐ。

観測者ルシエルは災厄の夜、人々の願いを保存するため朝を閉じ、帰還者まで閉じ込めた。ラシードへ届いた写しは彼女の保管記録の一部だが、原本の歌い手は明かさない。最後の戦いは閉じた観測の輪を開く試練。ルシエルは生きて記録を守り、エイルとミラは再会し、人々は異なる記憶を抱いて次の朝を迎える。東の樹海の観測記号を第7章予告とするが、本編データは追加しない。

### ボス・予兆・反撃

既存の蓄積攻撃AI `crystalAct` にデータのみの `enemy-scripts.ts` を接続。第4・5章の分岐・数値・予約の優先順位を維持し、新しい戦闘エンジンは作らない。

クロックガードとドローンは実行行動3周期。行動不能の機会は実行行動数を進めず、予約を保持する。クロックガードの防御は既存どおり次の本人の行動機会に解除される。

ルシエルはHP65%以下で第2段階、30%以下で第3段階。

- 第1段階：通常物理と威力60の光魔法「暁光術」を交互に使用。
- 第2段階：物理回避15%。実行行動数を3で割り余り2の時、防御して威力88の「時環の警鐘」を予約。
- 第3段階：同条件で防御し、威力110の「暁刻の終鐘」を予約。通常魔法74、通常物理1.15倍。回避は継続。
- 第2・3段階の魔法は15%で凍結、20%で沈黙、各2行動。命中後に既存の耐性・付与判定を通す。
- 予約時の威力を保存し、フェーズ移行でも上書きしない。行動不能で消さず、次の実行可能な行動で優先して放つ。
- 挑発→生存者選択→かばう→既存ダメージ計算→状態異常という同じ経路を使用。予兆は短い通知・防御アイコン・直近／詳細ログの文字で確認できる。

歯車の守衛はv1.3の砂兵の反撃を再利用。最初のHPを減らす物理被弾へ1回、攻撃力0.8倍。魔法・ミス・0ダメージ・撃破・被弾前の睡眠／凍結では反撃しない。麻痺判定、かばう、ガード、誓盾、実測イベント、連撃途中での攻撃者戦闘不能、反撃の再帰禁止も維持する。反撃は主攻撃のダメージ確定後・追加状態付与前、本人の次の行動機会まで有効。

## 時間のゆがみ・共通探索条件

`explorationRules` と `explorationState` が砂嵐と時間の両方を扱う。`sandstormState` は既存呼び出し用の互換窓口として残し、v1.3の発生・解除・制限を維持する。

|装置ID／地点|発生前提|静止中の制限|調律確定|
|---|---|---|---|
|c6-canal-clock／氷結した運河|c6-orphen|c6-canal-tune、c6-canal-fight、orphen-spring|c6-canal-tune|
|c6-corridor-clock／時環の回廊|c6-shield-gift|c6-clock-puzzle、eil-message|c6-clock-puzzle|

初期状態は「静止」。現地の装置で「進行」へ切り替えると対象行動が解放され、調律前は「静止」へ戻すことも可能。現在値・制限理由・解除方法を文字で表示し、操作後は即保存する。未知の装置、未知の値、重複操作、遠隔操作、未解放地点、前提未達成では変更しない。

調律完了後は「進行」を固定し、完了済みイベントや報酬を巻き戻さない。探索制限はUIだけでなく `completeEvent`、`beginAdventureBattle`、`collectQuestObjective` に共通判定を適用する。パズル画面を開いたまま静止へ戻して正解を送ってもAPIが拒否する。

過去の依頼達成記録の読み込みには「現在の時間が静止か」を使わない。進行中に回収した手掛かりを、後から静止へ戻しただけで失わせないため。既知ID・章／地点解放・依頼内前提は従来どおり検証し、第5章の砂嵐に対する既存の不正フラグ除去は維持する。

端末時計、実時刻、ランダム、待機時間は使わない。戦闘中の行動順やセーブの過去への巻き戻しを導入しない。

## 時刻切替パズル

既存cycleモードを再利用。左から「記憶・眠り・待つ人・一歩」の盤を **夕刻・真夜中・夜明け前・夜明け** に合わせる。

- 状態ID：`dusk` → `midnight` → `predawn` → `dawn` → `dusk`。
- 盤ID：`clock-memory`、`clock-rest`、`clock-wait`、`clock-step`。
- 初期碑文に加えて3段階の文字ヒント。1＝左2盤、2＝右2盤、3＝全解答と操作順。
- 誤答・リセット・無制限再挑戦、タップとキーボード操作に対応。
- 途中入力とヒント段階は画面内だけで保持。離脱・再読み込み後は4盤とも夕刻から安全にやり直せる。装置の進行状態は保存される。
- 解決の報酬は聖堂への道の解放と、手帳の「朝へ渡す歌の間隔」の追加（消耗品・経験値の追加付与はない）。正解で1回だけ進行を確定し、回廊と霜景色を夜明けの色へ変える。イベントを再訪しても報酬・進行は増えない。
