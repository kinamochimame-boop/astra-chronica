## 星力・複合効果のルール

- 各味方が戦闘開始時0、上限100。通常攻撃が実際にHPを減らすと＋15、通常スキル使用・防御で＋10。通常スキルが外れても使用が成立すれば＋10です。
- 実際の被HP減少1回につき＋10（連撃は各ヒット、毒・火傷は各継続ダメージ）。行動不能・無効コマンドから行動分は獲得しません。無効化された攻撃やミスでは被ダメージ分を獲得しません。
- 必殺技は100消費し通常の行動機会を使い、使用分の星力は獲得しません。MP・星力不足、未習得、対象不正、沈黙などの不成立時は資源・行動を消費しません。
- 戦闘終了・撤退で星力、挑発、誓盾をリセット。星力と習得リストは保存しません。既存セーブスキーマと旧形式読込は変更していません。
- 連撃は元のダメージ式・丸め・クリティカル・暗闇・属性・被ダメージ解除をヒットごとに処理します。同じ敵が途中で倒れたら残りを中止し、別の敵には移りません。
- 能力補正は既存どおり加算重複し、本人の行動終了で持続が減ります。自分へ付与した補正は発動した行動の終了でも減るため、疾風斬の直後は残り2です。疾風斬の自己補正は攻撃ミス時も付与します。素早さによる順番再計算は次ラウンドです。
- 挑発は生存中のみ有効。既存の「かばう」は挑発後の対象にも適用します。期限は本人の行動回数ではなくラウンド境界で減ります。
- 誓盾は生存者それぞれに独立した1回分を設定（再付与は1回へ更新）。直接攻撃の実HP減少で消費します。ミス・属性無効では残り、毒・火傷の既存割合ダメージには介入しません。防御・ガード・かばうと乗算します。
- 回復は最大HPを超えず、戦闘不能者を蘇生しません。奇跡はHP満タンでも状態異常があれば使用できます。全員に回復・解除の余地がない場合は使用しません。既存の沈黙仕様により魔法・回復系の必殺技も使用不可です。

## UIと確認手順

1. 通常戦闘の各カードでHP・MPと独立した星力を確認。スキル一覧は上下へスクロール可能で、必殺技が上部に表示されます。未習得Lv・MP不足・星力不足の理由を確認してください。
2. 連牙斬の2つの実測ダメージ、単体対象の維持、攻撃成功後の星力を確認してください。
3. 全体回復・守護の陣・必殺技では「生存する味方全体」と複数の対象マーカーを確認。全体対象中の個別タップでは対象が変わりません。
4. 早く試す場合、ホームの「戦闘基盤テスト（保存なし）」へ進み「検証レベル」で3/5/7/10を選択（戦闘リセット）。「効果付与対象」に味方を選び「星力を100に」で必殺技を試せます。本編のレベルと保存には書き込みません。
5. 各キャラクターの手番まで進め、コマンドから新スキルを選択します。回復は先に対象を負傷させ、奇跡の解除は状態異常付与後に確認します。敵の攻撃停止・固定乱数・旧シナリオも引き続き利用可能です。
6. iPhone Safari縦画面で一覧スクロール・最下段スキル・必殺技・実行ボタン、全体対象、HP/MP/星力、詳細ログを確認してください。演出中の連打、撤退直後の再戦、低モーション、再読込後の既存レベル維持も確認してください。
