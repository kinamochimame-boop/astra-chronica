## 物語と進行

エリシアの宛先である海底の観測港から、空と地底を結ぶ循環路をたどる。地下都市の住民は、事故と研究に関する記憶の一部を自ら封じて暮らしてきた。出生の記録を探すノア、防衛隊長ガルド、管理者リュシアと共に、「忘れることで守られたものと、思い出すことで失われるもの」を考える。

リナは知ることを急がせず、アステルは現在の暮らしと退路を守って前進を決め、メイは負荷を分けて記録を開く緩衝路を読む。ガルドとの対立は避難と停止手順の合意へ変わる。メモリアを倒した後も封印を一律に解除せず、住民ごとに読む範囲と速さを選ぶ。ノアの出生の詳細と18章の核心は明かさない。次の手掛かりは東の海辺の観測所。

### ボスの行動と予約

- ガーディアン：基本3行動周期。通常攻撃→防御＋反撃＋「封域波」の予兆→生存中の味方全体へ土魔法88。予兆は文字と既存の戦闘演出で表示する。反撃は既存の一度限り・物理被弾・行動不能時不可の規則。予約した範囲攻撃も睡眠等の行動不能では消えない。
- メモリア：HP65%超が第1段階、30%超65%以下が第2段階、30%以下が第3段階。第1段階の周期最初は防御を優先。第2段階は土魔法84と予兆118、第3段階は土魔法100と予兆145。第2段階以降の魔法は睡眠15%・沈黙20%（2行動）。フェーズの文字ログと予兆表示を使う。
- 強攻撃予約は既存の `charged` に威力を保持。フェーズが変わっても、予約済み118が145に上書きされたり、行動不能で消えたりしない。解放後の次の予約から新しい段階を使う。

範囲攻撃の追加フラグは新しい敵プロフィールだけで使用する。生存味方の順に、既存の `damage` / `applyEffects` を1回ずつ呼ぶ。挑発は全体対象を1人に集めない。かばう・防御・星力・一度限りの誓盾は実際に被弾する対象へ各ヒット単位で適用。かばう役が途中で倒れたら、その後の対象には肩代わりしない。反撃による無限ループは既存規則で防ぐ。各ダメージは `effects` に実測イベントとして格納し、v1.6のサイドビュー・ポップアップがそのまま描画する。旧敵のプロフィール・式・予約規則は変更しない。

### 共通エンジン

- `WalkMap` に章・地点・サイズ・グリッド・入口・対象・敵・テーマ・追加の必要イベントを定義。`MapObject.requires` で出口等の個別条件を指定する。
- `transitions.ts` は現在マップ、移動先存在、章、地点、必要イベントを副作用なく確認する。実際の変更は既存の `visitLocation` / `enterMap` が行う。不明な移動先は通知し、例外で画面を止めない。
- 4近傍A*を維持。移動中に同じ直線上へ再タップした際、現在セル中心へ逆戻りせず、前方の次セルへ向かう。曲がるときはセル中心を通り、壁の角を斜めに横切らない。通行不能地点へのタップは以前の経路を停止して通知する。
- 130px/秒・フレーム時間による移動、向き、歩行状態、カメラの上下左右制限を維持。背景復帰の長い経過時間は0.25秒に抑え、0.05秒単位の接触判定で飛び越えを防ぐ。
- NPC・宝箱・調査・出口は近接範囲で操作し、近くの対象を拡大・ネイティブボタンでも表示。出口に↗を付ける。敵は待／巡／追の文字ラベルと当たり判定半径に対応する輪を表示する。
- 出現は正規メインイベントの解放状態、撃破はその完了状態から導出。新しい追跡敵もA*で障害物を迂回し、ホーム位置からの距離制限で戻る。待機・巡回・追跡、画面外更新抑制、メニュー停止、接触ラッチ、安全復帰は既存の共通処理を再利用する。
- 画面破棄時は経路・タイマー・イベントリスナー・Phaserを破棄し、旧マップのAIを持ち越さない。touchendの合成クリック抑制とドラッグスクロールを維持。低モーション時は歩行上下動・接触フラッシュを省く。
- `map-art.ts` がテーマ別の色・構造物を描画。洞窟の岩・結晶、都市と市場の建物・灯り、水路と橋、採掘設備、記録庫の本棚・端末、中枢の装置・危険域を表す。既存の森・空3マップずつは従来の配色を維持。正式画像はこの描画境界で差し替え可能。音声・外部画像・新ライブラリなし。

### 戦闘との接続

歩行・敵AIを止める→接触元・serialを確定→共通サイドビュー戦闘→既存の勝敗・EXP・装備・イベント報酬確定→元マップの安全入口→撃破済み反映→保存。撤退・敗北は未クリアで再挑戦。途中リロードは未確定戦闘を放棄し、EXP・戦績を増やさない。勝利直後のリロードで二重報酬を受け取れない。

## セーブ互換

保存キー `astra-chronica:v1` / schema version **2** を維持。追加の永続フィールド・専用保存キーは不要。既存の章・イベント・選択・依頼・装備IDテーブルへ登録することで、第9章のデータを正規化・保存する。

- 第1〜8章、レベル・EXP・装備・90ノード・道具・依頼・選択・砂嵐の道標・時間状態を保持する。
- 旧セーブに第9章データがなければ未開始であり、選択や報酬を推測して付与しない。
- 第7・8章の有効な旧マップ座標・撃破・開封記録を保持する。第9章も同じAPIで復元する。
- `defeated` / `opened` は保存された自己申告を信用せず、全章の正規イベント完了から再構築する。
- 未知マップ・未解放マップ・壁の中・非有限値・範囲外座標・敵との重なりは既存の安全入口へ正規化。不明イベント・選択・依頼を除外しても、他の章や装備は失わない。

- 保存なし戦闘基盤テストは従来どおり独立したLabSessionで、本編の進行・所持品・マップを書き換えない。

### 修正した挙動とテスト調整

- 直線上での移動中再タップが現在セルの中心へ逆戻りする点をA*の出力経路で改善。曲がる際の角抜け防止は維持。
- マップ上の謎解きを正解した際は、イベント確定後にモーダルを閉じて歩行を再開する。通常地点UIの既存パズルの動作は維持。
- 追加したイベント条件を含む出口を共通APIで検証し、未知の出口定義を非nullアサーションで処理しない。
- ブラウザテストはマップ再生成後に読み取り用stateが公開されるのを待つ。追従カメラが移動中の再タップでは投影座標が変わるため、第7章も第8章と同じ実歩行ヘルパーで静止後の最終到達を確認する。元の到達座標のアサーションは残す。フィクスチャを切り替える試験では、画面終了時の自動保存と競合しないようホームに戻ってから投入する。
