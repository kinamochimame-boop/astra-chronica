# v3.8 探索ナビゲーション・マップ利便性

## 基準と変更範囲

最新main `ab9f7094387b0b8ad2f1c6ce3ec6a4f7cd503d1b` から `feature/v38-exploration-quality` を作成。戦闘計算・AI・成長・ビルド管理・章／イベント／マップ定義は変更しない。

## 操作

- 地面タップ、移動中の再タップ、対象への接近は既存MapRuntimeを使用。
- 通行不能な地面では2セル以内の候補を、距離と安定した座標順で検索する。既存findPathで到達を確認し、候補ボタンで確認したときだけ移動する。候補がなければ従来の移動不可表示。
- 「移動をキャンセル」で経路と候補を解除。イベント中・接触ロック中は受け付けない。
- 地図の「経路 ON/OFF」はミニマップとフィールドの控えめな線を切り替える。
- 「地図を拡大」で既知の地形だけを表示。停止・移動キャンセル・保存の既存処理を通り、閉じると探索を再開する。拡大地図からの移動指定は今回は追加しない。

## 経路と情報保護

navigationTargetが選んだ目的対象または解放済みの出口に、approachPointで安全な接近地点を求め、既存findPathを使用。経路の再計算は表示更新（最大10Hz）に従い、最新のプレイヤー位置と通行判定を参照する。独立した簡易経路は使わない。別マップへの案内は既存の出口グラフと解放条件を維持する。

経路線は未探索セルごとに分断し、未知の地形を線でつなげない。目的マーカーは発見済み地点のみ。未発見の宝箱・NPCは追加表示しない。全行程が既知になるまでは経路の一部だけが見える。マップ名はSVGの読み上げラベルと拡大地図の見出しに表示。

## 保存データ

キー `astra-chronica:v1`、version:2を維持。任意フィールド `survey` にマップIDをキーとして以下を保存する。

```ts
{format:1,width:number,height:number,seen:number[],walked:number[]}
```

セルは `y*width+x` の整数で保存し、重複を除去・昇順に整列。未知マップ、寸法・形式違い、セル数超過、非整数、範囲外は当該マップの履歴を破棄。通過セルは探索済みセルに限定する。全マップのセル数を上限とし任意巨大配列を採用しない。旧セーブでフィールドがなければ発見情報を推測しない。実際の探索から記録する。

位置とイベントは従来のworld、safePose、normalizeWorld、recoverWorldが担当。surveyは利便性のみで進行条件・報酬判定には使わない。保存は既存persistを通り、失敗は画面に通知する。保存なし検証は別Progressオブジェクトの記録となる。
