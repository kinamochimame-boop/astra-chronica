# v3.3 スマートフォン戦闘UI

基準：main `a312b1f423950c115f6dacbbb4c84f352f220f65`（v3.2）。

## 改善内容と操作

味方3人のカードは常に横並び。HP・使用可能EP・予約済みEP・CTを表示する。
カードタップで操作キャラクターを選び、技一覧→対象→予約の順で操作する。
味方対象は専用の3人ボタン、敵対象は敵カードで選ぶ。全体技は「生存する味方全体」と表示。
予約列にはキャラ名・登録順・技名・実際に消費したEP・取消記号を表示し、タップで全額返却する。
同じ選択技の再タップによる取消も維持。空の予約列は非表示。技と予約列のみ内部スクロールする。

行動可能時はカード外周が静かに発光する。選択中は◆、行動中は▶、HP25%以下は警告、
戦闘不能は暗転、状態異常は文字アイコンで区別。状態ボタンから残り通常攻撃機会を確認できる。
AUTO OFFではREADY・手動を表示。睡眠・凍結は発光させず、充填完了時の手動ボタンを
「行動機会を進める」と表示する。既存エンジンが行動制限を判定し、持続回数を進めるためであり、
行動不能中に攻撃を成功させる変更ではない。麻痺も実際の判定はエンジンに委ねる。

## 表示の計算と演出

残りCT＝`max(0, chargeInterval(id) × (1 − clamp(slot.progress, 0, 1)))`。
初回は既存のSPD補正後CT−4秒、次の攻撃から通常CT。独自時計は使わない。
小数第1位、1倍速換算の戦闘時間を表示する。速度2倍・3倍では実時間が1/2・1/3となる。
一時停止中は同じ進捗を表示し、SPD変化時は最新のCTを参照。非有限値は表示しない。

ダメージ・会心・WEAK・RESIST・MISS・ヒット番号・回復は既存BattleEventを表示する。
数値の再計算はしない。連続・同時攻撃には3レーンの表示位置を割り当てる。
通常攻撃EPはpublish後の実際のEPと直前の観測値との差だけを表示する。
予約・取消は観測値を同期するため、返却を通常攻撃の獲得と誤表示しない。
双剣は実測+2、上限直前は実測+1、上限時はポップアップなし。
回復対象は短く発光。演出の寿命も既存シミュレーション時計で管理し、破棄時にDOMを除去する。
低モーションでは移動演出を省き、数字・文字・枠を残す。
