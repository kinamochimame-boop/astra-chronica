## 遊び方と7地点

ホームの「冒険へ出発」から霧の森へ進みます。地点一覧は縦スクロールで表示し、未解放地点は選択できません。解放済み地点へは自由に戻れます。

|順番|地点|イベント|
|---|---|---|
|1|星灯りの野営地|アステル・リナ・メイの出発会話|
|2|霧の森・入口|戦闘前会話、通常敵3体との初戦|
|3|古びた石碑|星詠みの文字と三つの印を調べる会話|
|4|森の分かれ道|初回限定の宝箱（風切りの弓1個）、番狼たちとの戦闘|
|5|忘れられた泉|休息と三人の会話|
|6|星詠みの祭壇|森の異変と守護獣の予兆を伝える会話|
|7|霧の森・最深部|ボス戦、章クリア、後日談、第2章予告|

story / battle / treasure / rest / boss / clear の6種・9イベントです。各定義は安定したID・地点ID・前提イベントID・会話ページ等を持ち、完了状態はセーブ側で別管理します。後続章は同じChapter型とレジストリへ追加できます。第2章以降の内容は実装していません。

会話は話者・本文・ページ数・「次へ」で進み、最後の操作でイベントを確定します。会話を中断した場合は完了しません。ページ位置は保存せず、安全なイベント開始前から読み直します。スキップ機能は追加していません。会話中に戦闘は進行しません。

初回限定の宝箱・探索戦闘は完了後の再取得・再戦を禁止します。既読の物語・休息・後日談は読み返せます。繰り返しの戦闘は既存のホーム「戦闘開始」から引き続き利用できます。

## 敵とボス

|敵|HP|攻撃|速度|特徴|
|---|---:|---:|---:|---|
|霧まといのスライム|190|12|12|耐久型|
|影羽コウモリ|110|13|27|高速型|
|森の番狼|140|17|19|攻撃型|
|霧喰らいの守護獣|920|22|17|単体ボス、予兆付き強攻撃|

防御は各10。入口はスライム・コウモリ・番狼（経験値35×3＝一人105）。分かれ道は番狼・コウモリ・番狼（経験値50×3＝一人150）。ボスは1体で一人180です。個別の戦闘コピーにスロットID enemy0〜2を割当て、定義への状態漏れを防ぎます。

ボスは実際に行動できた回数に従って「通常攻撃 → 霧の吸収（攻撃なし・次回の強攻撃をログ通知）→ 霧裂き（攻撃威力1.7倍）」を繰り返します。行動不能時は既存のスキップ処理を使い、予兆後の強攻撃を勝手に消費しません。火に1.25倍、水に0.75倍の相性を持ちます。既存の防御・ガード・かばう・挑発・星力・状態異常が適用されます。

初期レベル・初期装備でも、単体集中・通常攻撃・強撃・ファイア・適時ヒールで攻略できるようにしています。入口・分かれ道・ボスそれぞれ20シードの初期パーティ戦闘完了をユニットテストで検証します。最終的な実機プレイ時間・長期バランスは未確認で、20〜35分を保証するものではありません。

## 保存・戦闘結果の一度限りの確定

既存の `astra-chronica:v1` キー、version 2、レベル・経験値・戦績・所持数・装備を維持し、`adventure` を加算的に追加します。

- `chapters[chapterId]`：現在地点ID・完了イベントID一覧。旧セーブは空の章進行（未開始）へ補完します。
- `serial` / `resolved` / `pending`：戦闘試行番号・確定済み番号・未確定イベント。戦闘を始める前に予約番号を保存します。
- 勝利・敗北・撤退の結果は未確定番号が一致する時だけ適用します。勝利の経験値・レベル・戦績・イベント完了・処理済み番号を一つのProgressへ反映し、1回のlocalStorage書込みで確定します。
- 同じコールバックを繰り返しても、古い番号を再送しても二重付与しません。新しい試行を開始すれば古い試行は無効になります。
- ボス勝利時はbossとclearの完了を同時に保存します。章クリア演出を表示した直後に閉じてもクリアが失われません。
- 敗北・撤退は戦闘回数のみ1回加算し、イベントは未クリアです。再挑戦できます。
- 戦闘途中の再読み込みではHP・MP・行動位置を復元せず、現在地点の戦闘開始前から再挑戦します。中断自体は勝利・敗北の戦績へ数えず、未確定報酬も付与しません。
- 未知の章・イベントID、依存関係を満たさない完了フラグ、不正な地点、破損した予約データは読み込み時に正規化します。既存の装備・成長とは独立しています。
- 宝箱は既存の `grantWeapon` を使用します。すでに弓を所持していれば1個追加しますが、宝箱自体は一度きりです。所持上限で追加できない場合は未完了のままとし、案内を表示します。
- 泉は会話と休息完了のみを記録します。各戦闘がHP・MP全快で始まる既存仕様を維持し、永続HP・消耗品システムは追加しません。

保存できないブラウザでは従来どおりメモリ上のプレイを継続し、探索操作時に保存失敗を案内します。保存失敗後の再読み込みは最後の保存状態へ戻ります。

## 維持した既存仕様

ホームの通常戦闘は従来の3敵・経験値・結果表示・再戦を維持します。保存なし検証画面は探索進行・装備・本編保存を変更しません。戦闘開始時の装備読込、既存スキル・必殺技・星力・状態異常・属性・バフ・成長・旧形式の読込は維持しています。Pagesワークフロー、Vite公開設定、外部依存は変更していません。

正式画像、背景画像、自由移動、ジョブは追加せず、地点の記号・CSS背景と既存のPhaser仮SDを利用します。

## iPhone Safari確認手順

1. 旧セーブから開始し、装備・レベル・経験値・戦績を確認。「冒険へ出発」で野営地のみ選べることを確認。
2. 会話を途中で中断／再読み込みし、報酬を受け取らず最初から読み直せることを確認。
3. 入口の戦闘で撤退し、未クリアのまま再挑戦できることを確認。戦闘中に閉じた場合も開始前からやり直せることを確認。
4. 入口に勝利→石碑→宝箱→分かれ道の戦闘→泉→祭壇の順に進む。宝箱再訪で弓が増えず、泉で成長値が変わらないことを確認。
5. ボスの吸収予兆が詳細ログに残り、次の強攻撃を防御・ガードで軽減できることを確認。勝利後に第1章クリア、後日談、第2章予告が表示されることを確認。
6. 再読み込みして章クリア・戦績・報酬が保持され、増えていないことを確認。装備・通常戦闘・保存なし検証画面も引き続き利用できることを確認。
7. 縦画面320／390／430px相当で、地点一覧・次へ・戦闘コマンド・ホームへの操作ができ、横にはみ出さないことを確認。
