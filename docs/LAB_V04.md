## 修正した点と維持した仕様

- 付与先と攻撃先が共通で、味方を選んだまま通常攻撃すると対象エラーになる問題を修正。**効果付与対象** は味方・敵全員、**攻撃対象** は生存中の敵のみです。回復・かばうには専用の味方対象欄を用意しました。
- 選択した攻撃対象が撃破されると、生存中の最初の敵へ自動切替しログへ記録します。敵全滅時は対象なし・行動ボタン無効です。効果付与対象は勝手に変えません。
- 自然解除・素早さの挙動は既存仕様どおりで、不具合として変更していません。確認しやすい操作と診断表示を追加しました。
- 状態異常・能力補正は本人の行動終了で1減少。行動不能のスキップでも減少します。指定した持続3は3回の本人の行動機会で解除されます。睡眠・凍結の定義上の既定持続2は維持し、検証条件では3を明示指定します。
- 睡眠・凍結は直接攻撃で1以上のダメージを受けると解除。継続ダメージでは起きません。麻痺は開始時判定、沈黙は魔法・ヒールを制限します。無効なコマンドではMP・持続を消費しないため、待機/通常攻撃で行動機会を進めます。
- 順番はラウンド開始時の実効素早さ降順で固定。同速は元の登録順。ラウンド途中では並べ替えません。アステル24→30でも先頭のままなのは正常です。
- メイ16→24なら、次ラウンドはアステル24の後の2番手になります。持続3を第1ラウンド開始時に付けた場合、第2・第3ラウンドは2番手、第4ラウンドでは期限切れで16に戻り5番手になります。
- 基礎/実効能力値、ダメージ、状態異常確率、属性倍率、成長、セーブ形式・キー・旧形式読み込み、GitHub PagesワークフローとVite設定は維持します。通常のゲーム画面に詳細ログを追加していません。

## 操作

ホーム → **戦闘基盤テスト（保存なし）** を開きます。

- **敵の攻撃を停止**：敵の通常攻撃を待機へ置換します。敵の行動機会、毒・火傷、期限処理は進みます。チェックを外すと通常攻撃へ戻ります。
- **効果付与対象の行動機会を1回進める**：途中の全員は攻撃せず待機し、選択対象の行動機会を1回だけ消費します。状態異常による制限があればスキップします。HP・MP・戦績は本編と共有しません。
- **次ラウンドまで進める**：全員待機で次ラウンドの先頭まで進めます。効果・期限切れは通常どおり進みます。
- **条件をセット**：検証戦闘を初期化して選択したシナリオを設定。睡眠/凍結の自然解除はアステルへ持続3、被攻撃解除は星喰いの影へ持続3、素早さはメイへ+50%/持続3を付与します。敵の攻撃停止も有効にします。
- **乱数**：通常乱数、seed42、固定0.99、固定0を選べます。変更時は検証戦闘だけリセットします。固定0.99は非会心・麻痺の行動不能なし、固定0は会心・麻痺行動不能あり。状態付与確率0%/100%はその設定の影響を受けます。

「ラウンド確定順」は開始時点のスナップショットで、残り順はそのラウンドでまだ行動していない生存者です。「次ラウンド候補」は現在の実効能力による仮計算で、途中の期限切れによって実際の次ラウンド確定順と異なる場合があります。

検証ログには行動者・実際の対象、行動前状態、制限、残り回数の前後、解除理由（期限切れ/被攻撃/手動/戦闘不能）、補正の付与・重複・失効、ダメージの入力威力・実効攻撃/防御・防御補正・属性倍率・ガード・かばう・会心倍率を表示します。かばう倍率は入力威力に反映済みと明示し、二重乗算して見せないようにしています。ログは最大1200行、リセットすると消えます。


## iPhone Safariでの実機確認

今回はmainへのマージ・本番公開を行っていません。レビュー環境、同じLANの開発サーバー、またはユーザーがレビューしてマージ・Pages公開した後に確認してください。ブラウザでv0.4の表記があることを確かめます。

1. 本編の戦績・レベルを控えてから検証画面を開く。「効果付与対象＝アステル」「攻撃対象＝星喰いの影」を別々に選ぶ。効果付与対象をメイ等へ変えても攻撃対象が変わらないことを確認。
2. 乱数を「固定0.99」に変更。「睡眠の自然解除・持続3」をセットし、対象の行動機会ボタンを3回押す。前後表示が3→2、2→1、1→0となり、「期限切れ」で解除され、HP180のままになることを確認。凍結でも同じ手順を行う。
3. 「睡眠の被攻撃解除」をセットし、通常攻撃で1行動進める。「被攻撃」で解除されることを確認。凍結でも繰り返す。自然解除とログ理由が異なることを確認。
4. 「素早さ検証・メイ+50%」をセット。確定順ではメイ5番手16、候補では2番手24。「次ラウンドまで進める」を押して第2ラウンドのメイ2番手を確認。さらに2回押して第4ラウンドのメイ5番手16へ戻ることを確認。
5. 乱数固定0/0.99で麻痺の行動不能/可能をそれぞれ確認。メイへの沈黙は持続3を付け、本人の機会を3回進めると次からファイアを使えることを確認。拒否されたコマンドだけでは期限は減らない点に注意。
6. 各属性の弱点1.5・耐性0.5を設定し、無会心の基礎32攻撃が48/16になることを確認。無属性はどちらも32。効果付与対象を相手の敵、攻撃対象も同じ敵にして属性設定を押す。
7. 敵を撃破すると生存敵へ自動切替し、選択肢から撃破済みの敵が消えることを確認。ヒール/かばうは専用の味方欄で選択できることを確認。
8. 経験値プレビューや各検証操作を行いホームへ戻る。本編の戦績・レベル・能力値が変わらず、再読み込み後も維持されることを確認。
9. 小さい縦画面でも横にはみ出さず、ボタン・チェック・selectをタップできることを確認。テスト画面は縦スクロールします。
