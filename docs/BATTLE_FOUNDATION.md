# 第3弾：戦闘基盤と検証手順

第2弾のmainを基準に拡張。既存の三人・役割・コマンド・localStorageキー・GitHub Pagesワークフロー・Vite相対パスを維持しています。正式UI・画像・ジョブ変更は追加しません。

## 定義と実行処理

|ファイル|責務・調整場所|
|---|---|
|`src/types.ts`|属性・状態異常・能力補正・ユニット・スキルの型|
|`src/data/combat.ts`|味方・敵の能力、使用コマンド、属性耐性、状態耐性、獲得経験値、スキル定義|
|`src/data/effects.ts`|状態異常の確率・持続・効果、属性名、補正上限・防御計算定数|
|`src/effects.ts`|付与判定、再付与、解除、能力補正、行動終了処理|
|`src/battle.ts`|ラウンド・行動順・スキル解決、行動不能スキップ、敵自動行動用API|
|`src/progression.ts`|レベル上限・必要経験値・成長量|
|`src/save.ts`|旧セーブの読み取り・schema v2への移行・成長データの検証|
|`src/lab.ts`|保存と分離した、手動ステップ式の仮検証画面|

スキルの `kind`・`element`・`power`/`attackScale`・`statuses`・`modifiers` をデータで設定します。例えば `statuses:[{id:'poison',chance:0.5,turns:3}]`、`modifiers:[{stat:'defense',amount:-0.25,turns:3}]` を設定できます。状態異常は攻撃が外れた場合と撃破済み対象には付与しません。ユニット固有の `attackStatuses` で通常攻撃・強撃の追加状態異常も定義できます。敵の通常攻撃でも同じ追加効果処理を利用し、かばうが発生した場合は肩代わりした者に付与します。

現行の通常戦闘ではファイアに25%の火傷を追加しています。毒・麻痺・睡眠・暗闇・沈黙・凍結と能力補正は、検証画面または定義/APIから試せます。今回はそれら専用の本編コマンドや治療スキルは追加していません。

## 状態異常

|状態|標準確率|持続（本人の行動回数）|効果|
|---|---:|---:|---|
|毒|70%|3|本人の行動終了時に最大HPの5%ダメージ|
|麻痺|60%|3|本人の行動開始時、50%でその行動をスキップ|
|睡眠|60%|2|行動不能。直接攻撃で1以上のダメージを受けると解除|
|暗闇|70%|3|物理攻撃の命中率50%。魔法は影響なし|
|沈黙|70%|3|ファイア・ヒールなどmagic/heal種別を禁止。通常攻撃・防御等は可能|
|火傷|50%|3|本人の行動終了時に最大HPの3%ダメージ、物理攻撃力20%低下|
|凍結|50%|2|行動不能。直接攻撃で1以上のダメージを受けると解除|

付与確率はスキル/API指定があれば優先し、実効確率は `指定確率 × (1 − 対象の状態耐性)`。同じ状態は多重化せず、残り回数を長い方に更新します。異なる状態は併存します。残り回数は本人の行動終了（スキップ含む）に1減り、0で解除。睡眠・凍結は毒・火傷の継続ダメージでは起きません。毒・火傷は最低1ダメージ、HP 0にもなります。戦闘不能時には状態・能力補正・防御・かばうを消去。新しい戦闘へ持ち越しません。

行動不能判定は開始時に保持され、ボタン表示のたびには再抽選しません。UIはスキップも敵行動と同じ待機処理で自動進行します。検証モードは意図的に手動進行です。

## 属性・能力補正

火・水・風・土・光・闇・無属性を定義。対象の `affinities` は属性ごとの倍率で、未定義は1。弱点1.5、耐性0.5、0なら無効を設定可能。無属性は常に1です。固定の循環相性ではなく敵ごとに設定します。現行の霧の番人は火弱点・水耐性、夜の使いは火耐性・光弱点です。

通常攻撃・強撃はユニットの `attackElement`（初期は無属性）、ファイアは火属性です。ダメージは概ね以下です。

```
物理基本威力 = 基礎攻撃力 × 能力補正 × 火傷補正 × スキル倍率
魔法基本威力 = スキル定義の固定威力
最終ダメージ = 基本威力 × (10 / max(1, 補正後防御力))
              × 属性倍率 × 防御/かばう軽減 × クリティカル倍率
```

四捨五入し、属性無効以外は最低1。防御力の基準値を10にして、第2弾のレベル1・補正なしの威力を保っています。攻撃力補正は物理攻撃に適用し、固定威力の魔法・回復は変えません。防御力は物理・魔法の両方に作用します。素早さは次のラウンドの並び替えから反映し、今のラウンド内で行動を重複させません。

能力補正は攻撃・防御・素早さごとに管理。同符号を加算し±75%で上限、残り回数は長い方へ更新。正負は別に保持して合算し、最終補正も±75%に制限します。終了時の回数減少・解除は状態異常と同じです。自己への効果を行動中に付与した場合、その行動終了も1回に数えます。ガード・かばうは従来どおり本人の次の行動開始までです。

## 経験値とセーブ

勝利時のみ、全員（戦闘不能者を含む）に敵の経験値報酬合計を付与します。現行は40×3=120を一人ずつ獲得。敗北・撤退・検証画面では本編に経験値を付与しません。

次レベル必要経験値は `100 + (現在レベル−1)×50`、上限50。余剰経験値を繰り越して複数レベル上昇可能、上限到達後は余剰を0にします。1レベルごとの成長はHP+12・MP+3・攻撃+3・防御+1・素早さ+1です。次の戦闘開始時に成長値を適用して全回復。ホームのレベル・編成の能力表示にも反映します。

保存キーは `astra-chronica:v1` のまま、内容の `version` を2にします。旧version 1は開始済み・勝利数・戦闘数を維持し、全員Lv.1/EXP0として移行。version 2の各人の成長値は個別に検証し、壊れた人物の項目だけを初期値に戻します。起動時には読み取りだけを行い、通常の開始/勝敗保存時に新形式を書き込みます。戦闘途中や一時的な状態異常・バフは保存しません。

## 実行するテスト

```sh
npm test
npm run build
npm run preview
```

別ターミナルで、Chromiumを用いたタッチ操作テストを実行します。

```sh
BASE_URL=http://localhost:4173 npm run test:browser
BASE_URL=http://localhost:4173 npm run test:foundation
BASE_URL=http://localhost:4173 npm run test:modifiers
```

`CHROMIUM_PATH` でブラウザのパスを変更可能（既定 `/usr/bin/chromium`）。自動テストには、既存コマンド・勝敗・MP、全状態の確率と解除、全員行動不能からの復帰、属性倍率、能力補正・順番、敵の追加状態とかばう、経験値の繰越と上限、旧セーブ移行、独立した検証画面が含まれます。Chromiumの検証はiPhone実機Safariの代替ではありません。

## iPhone Safariでの確認

PRマージ前はこのブランチをローカル起動し同一LANで接続するか、レビュー環境を利用してください。今回はmainへのマージ・本番公開は実施しません。レビュー後にマージした場合、既存のPagesワークフローで公開されます。

1. 既存の勝利・戦闘回数が残っていることを確認。通常戦闘を勝利まで進め、一人ずつ経験値120・Lv.2が表示されることを確認。
2. ホーム・編成でレベルと能力の上昇を確認。Safariで再読み込みしても保持されること、敗北/撤退で経験値が増えないことを確認。
3. ホームの **戦闘基盤テスト（保存なし）** を開く。対象・状態・確率・持続を選び、**状態異常を付与**。0%は失敗、100%は成功することを確認（検証初期ユニットは耐性0）。
4. アステルへ毒/火傷を付与し、「行動の対象」を敵に変えて通常攻撃を選び **1行動進める**。ログと本人のHP減少、残り回数の減少を見る。睡眠/凍結は行動スキップと自然解除を確認。
5. **戦闘をリセット** 後、全6人に睡眠を持続1で付与。**1行動進める** を6回押し、次ラウンドで行動可能になることを確認。
6. メイの行動まで進め、メイへ沈黙を付与。ファイア/ヒールは失敗しMPが減らず、通常攻撃/防御は使えることを確認。**状態異常を解除** で元に戻ることを確認。
7. 能力補正を繰り返し付与し、攻撃/防御/素早さの数値・上限・期限を確認。属性を設定し、対象を攻撃したログの弱点/耐性を確認。無属性は相性設定にかかわらず等倍になることを確認。
8. **経験値120を試す（保存なし）** で成長を確認し、ホームへ戻る。本編の戦績とレベルが変わっていないことを確認。
9. すべて縦画面で横にはみ出さず、selectやボタンをタップできることを確認。長い検証画面は縦スクロールします。

## 能力補正と攻撃を確認する際の対象

「効果の対象（付与・解除・相性）」と「行動の対象」は独立しています。前者をアステルにしたまま、後者を星喰いの影へ変更できます。補正付与の成功表示には対象名・能力・補正前後の実効値が出ます。ユニット欄の「攻」は実効値、「基礎攻」は補正前の基礎値です。物理攻撃後には、実行時に使った基礎/実効攻撃力も表示します。期限切れで攻撃後の値が変わった場合にも確認できます。

アステル、攻撃力+25%、持続3を選んで「能力補正を付与」を押すと、実効値32.0→40.0になります。「行動の対象」は星喰いの影、「コマンド」は通常攻撃で「1行動進める」を押してください。無属性・敵の防御10・クリティカルなし・火傷なしなら40ダメージです。付与先を変えずに再付与すると+50%で48、+75%上限で56。解除後は32へ戻り、持続1では40の攻撃を行った後に失効し、次のアステルの通常攻撃は32へ戻ります。残り1で使用後に表示が32へ戻るのは、攻撃後の期限切れです。

`npm run test:modifiers` は乱数を固定してクリティカル等を除外し、実ダメージ・HP減少・補正保持・解除・重複上限・期限切れと保存不変を確認します。
