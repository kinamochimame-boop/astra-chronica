# v3.2 戦闘スタート待ちと初回CT

基準main `f5c1e6db6d579274f4bc728372aca13a174d9f52`（v3.1 PR #32マージ済み）。作業ブランチ `feature/v32-battle-start-first-ct`。mainへマージせず、Pagesへ公開しない。

## 開始待ち

通常戦闘・章イベント・シンボル接触・ボス・再戦はすべて、戦闘画面を表示した直後はスタート待ちとなる。中央の「スタート」をタップするまで味方・敵とも動かない。

`AtbCombat.started` と一時停止を分離した。待機中は時間、通常攻撃ゲージ、HP/MP/EP、予約、状態異常・能力補正の残り回数、ラウンド、敵AIを進めない。攻撃・技予約もエンジン側で拒否する。AUTO・速度・対象などの表示設定は変更できるが、開始にはならない。一時停止ボタンは開始まで無効。

PhaserのTweenとScene Clockも停止し、待機の上下動も止める。メニューを閉じてもスタート待ちは解除しない。画面離脱時はタイマー・入力を破棄し、描画の時間倍率を通常に戻す。

## 味方だけの初回短縮

通常CT `N` はv3.1の武器系統、実効SPD、上下限を適用した値。

`味方の初回CT = max(0, N - 4秒)`

敵は初回も `N` のまま。短縮はSPD補正・通常CTクランプの**後**に行う。例えば通常60秒なら初回56秒で、短縮した初回を0.8秒へ切り上げない。戦闘速度1倍のシミュレーション秒であり、2/3倍速はこれまでどおり全体を加速する。

初期装備・Lv1の例：

|キャラ|通常CT|初回CT|
|---|---:|---:|
|アステル|約6.667秒|約2.667秒|
|リナ|8秒|4秒|
|メイ|8.75秒|4.75秒|

スタート前の待ち時間は加算しない。0秒の場合はスタート後の最初のシミュレーションフレームで時刻0の行動として1回処理する。スタート関数は冪等で、連打しても短縮・攻撃・EP獲得を再適用しない。

各ユニットに戦闘内限定の `firstAttack` を持たせ、最初の通常攻撃機会を処理したら通常CTへ戻す。ミスも通常攻撃として消化する。睡眠・凍結・麻痺で行動できなかった場合も初回機会を消化し、以降は通常CTで持続を進める。これにより0秒の行動不能を連続処理して自然解除を早めない。特技・防御の予約だけでは初回短縮を消費しない。

初回充填中も実効SPD変更を参照し、正規化した進捗を維持する。SPD上昇で初回CTが0になれば次フレームで準備完了となり、0除算しない。AUTO OFFは短縮CT到達後も手動入力を待ち、敵は通常CTで進む。

## 維持する仕様

v3.1の9武器基準CT、SPD式、味方0.8〜60秒／敵0.8〜6秒・基準3.6秒は変更しない。通常CT終了後の進捗リセット・モーション排他、EP上限15・実命中ごとの獲得・4件予約・取消返却・特技CT、ダメージ・属性・敵能力値・装備・90ノードを維持する。

初回だけのCTは味方カードに「初回」、消化後は「通常」と表示する。通常CTと短縮条件はツールチップでも確認できる。既存の通常戦闘UIを再利用し、開始オーバーレイを消してもレイアウトを組み直さない。

保存キー `astra-chronica:v1` / schema `version:2` は変更しない。started／firstAttackは保存しない。既存の中断復帰は従来どおり同じ遭遇の安全な再挑戦で、新しい開始待ちと初回CTになる。全18章・161マップ・進行・装備・経験値・依頼・選択・エンディングは変更しない。開始前の撤退は従来の撤退処理を利用し、勝利報酬やイベント完了を付与しない。
