# v1.6 第8章「天穹の浮島と星を運ぶ翼」・共通サイドビュー戦闘

## 基準と範囲

main `6b39a73fe48b1573562a091c30dc629784e1dea1`（v1.5 PR #16マージ済み）から `feature/v1.6-chapter-eight-sideview` を作成。第7章クリア後に第8章を解放する。アステル・リナ・メイの役割、戦闘計算、既存スキル、星力、装備、90ノード、状態異常・属性・成長・保存キーを維持する。第9〜18章は予告のみで未実装・未解放。

## サイドビューの正式適用

第1〜8章の通常・中ボス・最終ボス、通常戦闘ボタン、第7〜8章の接触戦闘、保存なし検証で共通の `Stage` を使用する。味方は左、敵は右。ホームなど3人だけの画面は既存の横並び肖像配置を維持する。

- `battle-layout.ts`：描画・当たり判定・数値ポップアップの共通座標。味方3人を左の3レーン、敵1体は右中央、2〜3体は右の縦レーン、4体以上は右の2列へ配置する。
- `battle-actors.ts`：画像差し替えの境界。剣／弓／双剣、盾＋槍／フレイル／突剣、ワンド／ロッド／メイスを図形で描き分ける。剣士のマント、盾の構え、メイの帽子、敵の獣・スライム・翼・機械・精霊を区別。新敵は個別色、ボスは大きさでも区別する。
- `battle-animations.ts`：確定した `battleEventParts` を読み取り、実測値・対象・ヒット数・反撃・属性・会心・ミス・かばうを演出計画にする。描画側でダメージを計算しない。
- `visuals.ts`：待機の揺れ、行動者と対象のリング、短い踏み込みと復帰、弓／魔法の飛翔体、属性色の光、詠唱光、回復光、盾、防御、かばうの前進、被弾の明滅、戦闘不能の暗転、予兆・反撃・必殺技を描く。
- `battle-view.ts`：HP・MP・星力、状態詳細、コマンド、ログは既存DOM UIを維持。数値は共通座標へ表示。4体以上の敵情報を横スクロールにし、選択した敵のカードを表示範囲へ入れる。コマンドを画面下へ押し出さない。

通常攻撃は武器によって踏み込み／遠距離を切り替える。属性付きの物理攻撃を魔法と誤認しない。連撃・反撃・全体回復の各イベントを個別に描き、実際の対象へ数値を表示する。ミスはMISS、会心は金色、回復は緑、弱点／耐性はWEAK／RESISTを既存の表示規則で示す。状態異常のアイコン・残り回数は既存カードの詳細表示を使う。

### 進行と破棄

既存の850ms入力ロックと戦闘エンジンによる行動確定を維持。Phaserの完了コールバックをターン進行の条件にしないため、非表示・低FPS・描画休止でもアニメーション待ちの進行不能を作らない。低モーション時は踏み込み・揺れ・飛翔を省略し、短い静的な光と数値を残す。

再描画時は世代番号更新、遅延イベント・Tween・図形の破棄を行う。画面を離れたときは既存のターンタイマーとDOM UIを破棄し、共有Stageを次の表示へ更新する。Scene終了時はresize／gameイベントを解除する。検証画面も同じ描画を使うが、独立したLabSessionのデータだけを渡し、保存APIを呼ばない。

## 第8章の物語

セレスの西海の観測印は、海へ抜ける山脈の上で動く浮島の航路を示していた。操縦士アルカは自由に飛ぶことと誰かを乗せて戻る責任に迷い、整備長ヴァルトは暮らしと古い機構を支える。記録管理者エリシアは、戻らなかった便の宛先を保管している。

主題は「飛び立つ勇気と、帰る場所を守る覚悟」。アステルは前進を決め、リナは避難と帰還者の安全、メイは歌の間隔と浮遊炉の供給路を読み解く。守護者アストレイアは単純な悪役ではなく、古い帰港の約束だけを待ち続けていた存在。撃破後も今の空を支える役目を選ぶ。歌い手の名や全18章の核心は明かさず、第9章の海底観測港へつなぐ。

## 自由探索の共通化

`sky-port`（c8-port）、`sky-island`（c8-island）、`sky-ruins`（c8-ruins）の3マップを追加。第7章の3マップと同じ `MapRuntime`、A*、移動、カメラ、敵AI、近接／接触検証、イベントUIを使う。章ごとの新しい移動エンジンを作らない。地形グリッド生成だけを `map-grid.ts` へ抽出し、既存地形を維持する。

港はアルカ・帰港灯・調査案内・飛行艇の仮船体と桟橋、風の庭は空隙と橋・巡回敵・組紐、遺跡は壁・通路・観測盤・待機／追跡敵・箱・航路片を持つ。天空テーマの色で水面ではなく雲海と空隙を表現し、既存の通行不可タイルとして処理する。

港→桟橋→甲板イベント→風の庭へ移動。飛行完了後は港と庭の出口で行き来できる。庭から居住区・整備場・橋・花園・回廊を進めると、庭の遺跡側出口が開く。遺跡のイベントと接触戦闘を終えて、外郭へ出る。残り13地点は既存の地点選択式。

`access.ts` のchapter-07固定参照を除去し、各マップ自身のchapterIdの確定イベントから撃破・開封を導出する。ヘッダーも章番号をデータから取得する。第7〜8章のIDはそれぞれ独立し、同じ座標でも別章の敵を接触元に使えない。

## セーブと復帰

キー `astra-chronica:v1` とversion 2を維持し、新しい必須root項目を増やさない。既存world形式をそのまま読み、第8章のマップ・イベント・敵・箱を既存の定義テーブルへ追加する。撃破・開封配列は各章の確定イベントが正で、rawの未知IDや未撃破の偽フラグは採用しない。

同じマップへ戻る場合は安全な保存座標を使い、別マップ／別章の歩行地点へ切り替えた場合はそのマップの安全な入口へ移る。全マップ分の座標履歴は追加しない。位置の非有限値・壁・空隙・範囲外・未撃破敵との重なりは入口へ補正する。未知マップは既存どおり解放済みの安全なマップへ補正する。

戦闘終了は既存の試行番号と報酬確定処理で一度だけ反映。勝利した敵だけを消し、敗北・撤退後は再挑戦できる。未確定の接触戦闘をリロードした場合は報酬・勝敗を加算せず、接触元のマップの安全な入口へ戻す。旧章の戦闘中断方式は変更しない。保存なし検証のStage連携はLabSessionを読むだけで本編に混入しない。

- 複数ヒットで踏み込み位置が累積しないよう、保存した待機座標から毎回往復する。
